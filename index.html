Structured Content Archetype Clustering

Author: Umama Naseer | AI & Machine Learning Track Capstone

Abstract: This research paper presents an unsupervised machine learning approach (K-Means Clustering) to group unstructured search performance metrics into automated content management archetypes. Evaluating aggregated URL-level performance shows that multi-feature clustering significantly outperforms single-variable heuristic quantile baselines (Silhouette Score 0.2915 vs 0.0786).

1. Research Question & Decision Supported

Question: How can we group unstructured web content metrics into distinct performance archetypes using unsupervised machine learning, and assign automated playbooks (Protect, Improve, Refresh, Prune) to each group?

Decision Supported: Enables SEO and content teams to automatically prioritize thousands of URLs into lifecycle actions without performing manual line-by-line page audits.

2. Data Source & Scope

  • Dataset: FlyRank ML Internship Warehouse Dataset via DuckDB.
  • Metrics: Aggregated URL totals for impressions, clicks, ctr, and avg_position.
  • Exclusions: Zero-impression/inactive URLs filtered out to remove long-tail noise.
  • Privacy Guarantee: All domains and URLs are fully anonymized.

3. Methodology

  1. Feature Transformation: Log-transformation log(1+x) applied to heavily skewed metrics (impressions, clicks).
  2. Normalization: StandardScaler applied to standardize features (zero mean, unit variance).
  3. Clustering Model: K-Means algorithm evaluated across K ∈ [2, 6] using Elbow method and Silhouette scores.
  4. Dimensionality Reduction: Principal Component Analysis (PCA) used for 2D visual projection.

4. Results (K-Means vs Baseline)

Model Approach Silhouette Score Performance Gain
Quantile Heuristic Baseline 0.0786 Baseline
K-Means Clustering (K=4) 0.2915 +370% Separation

5. Honest Framing & Limitations

  • Findings reflect historical observational metrics, not causal ranking guarantees.
  • Seasonal search traffic fluctuations can alter cluster boundaries over time.
  • Unsupervised clustering categorizes content performance; it does not claim to prove Google's ranking mechanics.
